# K6 三灯蓝色 / 暖黄

K6每次开机后第一次按下给三灯设置蓝色（HSV h=240、s=1000），再次按下切回最暖白光（temp_value_v2=0），之后交替。
保留每只灯的开关状态和当前亮度；关着的灯仍关着。旋钮在蓝色模式调整HSV V，保持蓝色色调。

K1继续紫色/暖黄；K1和K6各自保存切换顺序，不互相重置：例如K1紫色→K6蓝色→K1暖黄→K6暖黄→K6蓝色。
两键均按每个处理的按键事件推进，不受单灯确认失败阻挡；部分失败逐灯记录。长按或释放不重复触发。

K2/K8/K9单灯开关、K4总开关、三灯旋钮、横屏两页、触摸卡片与校准均保留。副板不变，K6仍接副板GPIO18与GND。

验证：只刷主板。依次按K6两次检查三灯蓝色/暖黄，再交替测试K1/K6和旋钮，确认独立切换及色调保持；关一灯再切色应保持关闭。
日志显示COLOR K6 -> ALL BLUE/WARM WHITE和各灯accepted结果。本次尚未刷板，需上板验证。
