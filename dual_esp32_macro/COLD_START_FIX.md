# 冷启动恢复 v2

症状：共同上电时离线，副板Reset后恢复。修复目标是启动排序和I²C外设/总线恢复，不等于已经证明电源时序没有问题。

两块板都需要重新烧录：

- 主板：macro_main/macro_main.ino（同目录KeyBridge.cpp已更新）
- 副板：macro_secondary/macro_secondary.ino

主板开机等待1秒后先探测0x42，再等待20ms进入2ms读取；持续离线时每5秒最多恢复总线一次。副板等待300ms后初始化；初始化失败会重试，通信无活动3秒会重新初始化I²C并预装载TX，不重启CPU。重复无活动后退让到15秒间隔。

测试时先拔副板USB，保持由主板供电。断开主板USB和电池，确保整机真正断电几秒，再重新供电。不要按副板Reset，等约10秒看是否自动ONLINE，至少重复5次，再分别验证USB/电池供电、单键、组合键及触摸。

主板errors是历史累计数，恢复后不会自动归零；看online=1及错误数是否停止增加。

若仍失败，请保留副板从上电开始的[BOOT]/[SLAVE]日志和主板[I2C]日志。如果副板没有启动日志或持续brownout/reset，应进一步测量副板5V/3.3V与EN，软件外设恢复不能修复未启动的CPU。

旧源文件备份位于相邻 .bak-before-cold-start-20261023 文件；无需改变现有接线。
