# 狗狗灯泡卡片

按确认的概念图改造LIGHTS页，针对480×320小屏进行了布局/字体适配：
- FEIT / K9：黑白边牧。
- ROOM C2 / K8：金毛。
- ROOM C1 / K2：陨石色边牧。
- ON使用睁眼精神图样和奶油色卡片，OFF使用蜷缩睡觉图样和灰色卡片；未知状态显示?，不冒充OFF。

三卡变为x=12/168/324、y=82、144×188。卡片整块含ON/OFF按钮、狗狗图样均可点击，触摸区域已同步扩大；间隙和九键页不执行灯控。K4底部提示是物理总控键的下一动作，不新增底部触摸总开关。
两页共享深蓝绿背景、奶油色选中标签、爪印标题；九键页内容和逻辑不变。

所有三灯开关/颜色/旋钮后台、触摸按住防重复、K7左/K5右、屏幕恢复、I²C冷启动和副板保持不变。
HEALTH周期串口输出仍关闭。原NVS校准格式和坐标画布不变，通常无需重新校准。

## 图样与资源

六帧各128×108像素，合计83,200字节，128色共享RGB565调色板，直接编译进Flash，不需要SD或文件系统。
DogAssets.cpp为生成数据，assets/dogs保存AI生成原图、裁剪PNG及RGB565回转预览；tools/generate_dog_assets.py可用Pillow重建数据。
BoardDisplay增加索引图SPI流式绘制，只用128字节临时缓冲，无整屏帧缓冲。卡片仅在自身状态变化或整页恢复时重画，云端BUSY变化不会反复绘制三只狗。
素材由内置image_gen生成，完整提示词见assets/dogs/PROMPT.txt。

## 烧录与检查

仅更新主板macro_main，保留ESP32 Dev Module/4MB/默认分区。副板不更新。
1. 上电检查三只狗对应正确，切换ON/OFF观察睁眼/睡觉，未知状态仍显示?。
2. 点每卡上部、狗狗及下方ON/OFF按钮，确认只切对应灯；间隙不触发。
3. K7/K5和顶部标签切页，检查九键、旋钮与触摸校准仍正常。
4. 复测K1紫/暖、K6蓝/暖、K4总控、单控键和旋钮三灯调光。
5. 重启/重连WiFi或串口lcd恢复后仍横屏、狗狗正常且校准保留。
