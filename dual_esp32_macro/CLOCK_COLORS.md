# 本地时间、粉色与橘色

2026-10-25 已刷入 COM4 主板，副板不更新。页面顺序仍为 LIGHTS → WEATHER → 9 KEYS。

## 时间

三个页面顶部显示 24 小时时分秒、日期/星期、PST 或 PDT。联网通过原有 NTP 服务校时，不新建网络任务。
使用与 98074 一致的 America/Los_Angeles 时区，POSIX 规则为 PST8PDT,M3.2.0/2,M11.1.0/2。
UTC 时间戳和 Tuya 签名不变，只通过 localtime_r 转换显示。天气模块继续按 API 的当地日界处理预报。
首次断电重启尚未校时时显示 --:--:-- 和 WAITING FOR TIME；同步后断网仍可继续计时。
时钟只每秒局部刷新顶部 x34..213、y0..31，不覆盖 WiFi/I2C 状态、CAL 或翻页标签。

## 按键颜色

- K1：粉色 / 暖白。粉色 HSV H=6、S=118，V 保持该灯原亮度。
- K6：橘色 / 暖白。橘色 HSV H=30、S=1000，V 保持该灯原亮度。
- 两个按键独立交替，首次按下为对应颜色，每个处理过的事件推进一次，不依赖云端 ACK。
- 每盏灯的开/关状态显式保留，关着的灯不会因为选色而被打开。
- 选色后旋钮沿用缓存的色相/饱和度，只改亮度；暖白温度参数仍为 0。

原 K6 内部函数改名为 toggleAllOrangeColor；主程序调用同步更新。屏幕底部文字改为 K1 PINK / K6 ORANGE。
