# Feit 移植后屏幕只有背光的排查版

用户确认：九键版本曾正常显示，Feit K4 控制正常，但屏幕只有背光。
尚未通过实板日志确定根因；不能把目前的初始化时序恢复当作已确认修复。

变更仅在主板：
- 首次完整绘制界面后延迟500ms启动联网，避免 Wi-Fi 初始化与首次绘制同时发生。
- 每次检测到 Wi-Fi 从断开变为连接，等待500ms后重新初始化 ST7796 并强制重绘全部区域。
- 屏幕初始化期间 UI 会短暂停顿（约0.8秒）；I²C 扫描任务及 Feit 后台任务持续运行。
- 串口115200发送 `lcd` 加换行，可手动重新初始化并重绘。
- 在联网前、恢复前/后输出 `[LCD]` 原始寄存器读数，包含 D3 ID、0A 电源状态、0C像素格式及背光引脚电平。
- 某些面板没有接可读 SDO；全0或全FF并不能单独证明屏幕损坏。
- 屏幕引脚和初始化寄存器保持原稳定版本；九键、旋钮滤波、I²C 冷启动恢复及 K4 控制没有更改。

## 烧录验证

只烧录 macro_main，副板不变。上电观察：联网之前是否短暂有画面、联网恢复后是否有画面。
若仍只有背光，在串口发送 lcd，再观察画面，并保留全部 `[LCD]` 行及 `[FEIT] WiFi connected` 前后日志。
本机编译通过，但未烧录、未实测显示恢复。
