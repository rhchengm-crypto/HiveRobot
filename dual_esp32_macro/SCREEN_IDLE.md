# 五分钟息屏节能

已更新 COM4 主板，用户确认现有版本符合预期，保持当前规则。

连续五分钟无操作后，关闭 GPIO27 背光，并暂停屏幕绘制和狗狗动画。主板、WiFi 和 I2C 继续运行。
任意实体键按下一次会唤醒屏幕，并在同一次事件中继续执行原键功能；按键不会被息屏功能吞掉。
持键或触摸期间不息屏，松开后重新计时。有效旋钮转动会唤醒并继续调亮度。
触摸息屏屏幕时，首次接触只唤醒，稳定松开 40ms 后才接受下一次点击，避免盲点误切灯泡。
唤醒先重绘再开背光，保留原页面；LCD 恢复操作尊重息屏状态。

页面仍为 灯控 → 天气 → 娱乐热榜 → 9KEY（最后）；K1 为 01 奶油粉。副板不更新。

验证记录：四个页面的串口息屏/唤醒、GPIO27 低/高电平、暗屏 LCD 恢复检查通过。
编译期验证了 299999/300000ms 边界、持键、重新计时、九键通用唤醒及 millis 溢出。
连续五分钟串口测试在实测静置 57,299ms 后因电脑休眠中断，未记录到完整自动息屏事件；不将此项记为通过。
随后用户明确确认现有设备版本符合预期。原按键调度代码除新增唤醒调用外逐字保持，未实施“首次按键只唤醒”的临时提议。
息屏暂停动画已由主循环门控实现；没有声称完成暂停前后帧计数实测。
程序 1,300,507/1,310,720 字节，静态 RAM 73,088 字节；未改分区，只刷应用区并校验哈希。

串口 screen 查看状态，screen off / screen on 仅用于手动背光诊断；状态查询不重置计时。
备份源码 backup-before-screen-idle；更新前应用 work/screen-idle/application-before.bin。
