# 固定输入协议 V1：9KEY + POT

这份协议是后续只更新主板软件的兼容约定。副板只采集输入，不承担任何宏或电脑控制语义。

I²C：400kHz，主板master，从板7位地址0x42，两端SDA21/SCL22。主板一次请求恰好8字节，带STOP；不写寄存器索引。开机探测是零数据地址探测，不改变协议。与旧五键一字节固件不兼容，两端本次必须一起更新。

| 字节 | 含义 |
|---:|---|
| 0 | 固定标识0xA9 |
| 1 | 协议版本0x01 |
| 2 | 按键状态低8位：bit0~7=K1~K8，1=按下 |
| 3 | 按键状态高字节：bit0=K9，其他位必须0 |
| 4 | 电位器ADC滤波值低字节 |
| 5 | 电位器ADC滤波值高字节，数值范围0~4095 |
| 6 | 副板扫描发布序号，8位循环；用于观测，不是宏次数/按键序号 |
| 7 | 字节0~6的CRC-8/SMBUS：poly=0x07，init=0，非反射，xorout=0 |

16位字段均小端。九键全按为0x01ff，不是0xff。每个开关独立INPUT_PULLUP，接地按下；约1ms扫描、独立10ms消抖。电位器GPIO34（ADC1）12位、11dB衰减档，每约4ms采样，整数EMA滤波，系数1/4。ADC范围不是精确电压测量，端点/线性需应用侧标定。

副板在loop预计算完整帧，onRequest只在短临界区复制8字节快照，随后写Wire缓冲区；ADC、消抖、编码和CRC不在回调执行。经典ESP32 TX FIFO预装载可能让主板看到前一个快照，因此不把序号停留一个轮询周期判为故障。

主板仅接受长度、标识、版本、CRC、按键保留位和ADC范围均合法的帧。正常2ms读取，旋钮通知节流到最多约50Hz、死区32 ADC计数；按键/上下线变化不等待旋钮节流。断线100ms释放按键，保留电位器最后数值且标记OFFLINE。

宏映射、旋钮顺逆方向、百分比、音量/亮度/滚动含义和端点标定都由主板处理。已提供onMacroKey(key,down)、onPotChanged(raw)以及POT_REVERSED。副板没有接收配置/OTA协议；不增加输入硬件、不改引脚或通信格式时，后续应用变化无需重刷副板。若发现固件缺陷仍可能需要修复，不能承诺永远无需任何维护。

编译期验证：全部512种按键组合的消抖/释放、独立按键弹跳、millis溢出、5120种按键边沿转换、CRC标准向量123456789=0xF4、协议往返及各位单比特损坏、短帧/越界拒绝、ADC滤波单调性与端点收敛。
