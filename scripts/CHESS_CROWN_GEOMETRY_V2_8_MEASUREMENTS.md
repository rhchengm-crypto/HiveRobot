# 改装机械臂：几何测量与示教数据

## 当前实现范围

v2.8 增加“棋冠几何示教”页签。支持保存棋盘/机械臂坐标对应点、刚体变换拟合、
独立检查点误差验证、黑白12类/四个朝向的棋冠参数，以及抓放TCP坐标预览。
数据单独保存至 data/chess_crown_geometry_v2_8.json；不改动旧模型或动作库。

这里的机械臂XYZ需要实测或来自已验证的正运动学，不能用相机坐标或关节角代替。
当前没有可用于这台改装机械臂的确认模型。未实现逆运动学、整臂避碰、
视觉自动棋冠定位、自动开局空位选择及电机执行；预览始终 executable=false。
棋冠射线与已知高度平面相交的数学函数已有测试，但未接入实机相机外参。

## 第一批测量：确定关节链和末端

请保持同一个参考姿态，提供正面、侧面、俯视照片，标明肩、肘、腕各转轴。
关节名使用控制页面名称，但不要假设页面顺序就是实际机械连接顺序：
shoulder_front、shoulder_side、shoulder_rotate、elbow、arm_roll、wrist_side、wrist。
夹爪开合单独记录，不作为定位关节。

沿底座到夹爪，依次提供：

| 数据 | 怎么量 |
|---|---|
| 实际关节连接顺序 | 哪个关节的外壳承载下一个关节 |
| 每两根相邻转轴的相对位置 | 轴心到轴心；同轴也注明。提供前后、左右、上下偏移，单位mm |
| 各关节转轴方向 | 在参考姿态下，在照片上画箭头说明绕哪根轴转动 |
| 最后关节轴心到夹持中心 | 夹爪接触棋冠的中心，不是指尖；提供三个方向的偏移 |
| 夹爪外形 | 张开最大外宽、夹指厚度、指长；用于相邻棋子间隙检查 |
| 基座到棋盘 | 棋盘相对固定肩部参考点的位置和高度，提供测量方向 |

照片中的参考姿态，用现有“保存动作”保存为 geometry_reference；需要对应的
关节角记录来关联机械姿态和电机读数，不会将此动作当作抓放回放轨迹。
关节正方向、电机角零点和安全范围随后逐关节核对；未知值留空，不要猜。
尺寸不易量时先提供照片和可测的尺寸，再确定缺少哪些偏移。

## 第二批：棋冠参数

每类棋子记录：实际全高、适合夹持的棋冠部位距棋盘高度、该部位宽度、
张开所需宽度，以及夹持时夹爪工具中心偏移。单位mm。
knight等不对称棋子按front/back/left/right记录，必要时后续增加姿态。
先完成一种棋子，不必一次测全部12类。

## 部署本阶段

更新 chessboard_vision_v2_8_web_control.py，并把 chess_crown_geometry_v2_8.py
放到同一目录，保留旧依赖；重启v2.8即可看到新页签。
示教数据与坐标预览不会下发机械臂动作，即使服务有 --enable-execute。
原机械臂页的手动动作仍按原执行开关运行。

## 已验证的放置锚点

`placement_anchors` 保存“棋盘目标格 ↔ 已训练关节姿态”的对应关系，作为后续
几何拟合、邻近格插值和新动作训练的示教依据。它不会自动执行机械臂动作。

当前 `white_bishop:c1` 来自 saved move `white_bishop_place`。目标为 c1，棋冠
夹持中心的名义棋盘坐标为 `[137.5, 27.5, 55] mm`。2026-09-12 的完整回放中，
七个定位关节的最终误差均在 0.5° 内，因此记录为 validated。该动作当前只定义
到达 c1 的放置姿态，不包含松开夹爪。
