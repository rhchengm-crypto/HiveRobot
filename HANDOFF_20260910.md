## Work completed since 2026-09-06

### Chess vision and prediction display

- Prediction images now draw the selected per-square YOLO result, bounding box, class and confidence.
- Inspect can display the yellow board grid and green YOLO box together.
- Full-board crown projection maps a detection by the lower part of its box so tall pieces such as kings do not
  create a false occupied square one rank behind them.
- Inspect no longer requires a depth detection before running YOLO. YOLO can recover a piece missed by the depth
  geometry stage while retaining the original geometry result in `geometry_detection`.
- Height-assisted results retain the original RGB class and confidence semantics in their output and overlay.

### Height sampling and height-assisted identity

- Added RGB/depth height sample capture for all 12 chess-piece classes with train/val/test splits.
- Added metric board-plane calibration, sample validation, model building and test reporting.
- A height class is activated only after valid train/val samples and ruler-error checks pass. Test samples never fit
  the profile.
- Live height assistance abstains unless both the original and alternative classes have validated profiles and the
  measured height supports one unambiguous alternative.
- HP60C measurements observed during this session were not metrically accurate enough for absolute classification:
  a 40 mm pawn was commonly estimated near 8–10 mm and a bishop near 26 mm. Do not force-enable these profiles.
  Relative-height logic is promising but still experimental.
- An invalid wide object temporarily labeled `black_pawn` was removed from the intended dataset and must not be
  treated as a real chess-piece height sample.

### v2.8 integrated Web controller and arm geometry

- Added a crown-geometry teaching page and a non-executable pose preview. It does not yet run IK or autonomous grasp.
- Recorded the modified arm link measurements, qualitative positive joint directions, board reference points and

### Home, clearance and saved-move self-learning

- `scripts/left_arm_v2_8.py` wraps v2.6 Home and clearance. Home now forces every selected joint through the formal
  return after clearance, then performs one bounded verification pass from fresh feedback.
- Captured Home/clearance transitions receive a 5 degree limit margin only when the recorded endpoint is within that
  margin. Larger transitions are still rejected.
- Clearance learns a pose-local residual and validates participating joints at 0.5 degrees. The legacy 180 degree
  `shoulder_rotate` clearance deadband remains excluded from validation.
- `scripts/left_arm_v2_8_move_library.py` inherits the v2.6 shared adaptive parameters, then adds local corrections
  matched by seven-joint target-pose distance. Large pose changes create a new anchor.
- Before the final wrist motion, all six other joints must pass the tolerance. Failed checks save residuals and stop
  without an extra correction jerk.
- Wrist-induced hold errors learn once per completed wrist motion with bounded integral updates. The final seven-joint
  snapshot determines `training` or `validated` for each move.
- The nominal tolerance is 0.5 degrees. A 0.011 degree half-encoder-count comparison margin prevents an identical
  0.5027088 degree feedback bin from blocking forever; the effective acceptance edge is 0.511 degrees.
