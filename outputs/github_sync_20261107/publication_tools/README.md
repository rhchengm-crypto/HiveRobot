# Publication tool snapshots

These are byte-preserving snapshots of collection, verification and publication tools used from the original repository's `tmp/` directory. Their original `parents[1]` root assumptions are retained as evidence; do not run these archived copies in place.

The supported, hardware-free download entry point is `../restore_publication_data.py`, with `../publication_manifest.json`. All live robot controls remain in the ordinary `scripts/` source tree. No authentication token or SSH private key is embedded in these tools.
