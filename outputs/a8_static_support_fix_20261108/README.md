本轮先执行普通 Web Home 及结束后的 5 秒 Model Hold。用户确认：**“全程正常，目前稳定”**。随后仅做离线分析、代码修改和空闲状态代码同步；没有再次执行 A8、下降或闭爪。

## 原始实测及已确认的软件问题

- 前一轮 A8 空载测试无抖动、无接触，但用户目视发现：下降过程中累计向 A 列边界外偏约 20 mm，夹持区域还可下降约 15 mm。因此该轮不合格，不加入成功路径库、不参与成功样本拟合。
- 三次 `endpoint_settle` 重试使用同一目标、同一 Kp/Kd、同一前馈；肩前误差均为 2.5791°。在静态负载模型存在残差时，重复同一控制条件会停在同一误差平衡点。
- 终点的重力增量已经保留，不能再叠加一次目标重力。Model Hold 的等力矩接管保留了已有姿态误差，没有证据说明它造成了这次下降中的外移。
- 固定窗口的原始反馈及重试证据见 [recorded_window_audit.json](recorded_window_audit.json)。旧 v32 帧没有逐轴收包时钟，新观察器明确拒绝把这些旧帧当作可学习的新鲜反馈。

## 修复内容

版本：`seven-axis-board-grasp-v33-quasistatic-support`。

1. 在 SDK 每个电机实例的真实 `recv_data` 回调记录时钟与序号；反复读取缓存不会刷新时钟，不修改供应商 SDK 文件。
2. 仅在上方接近、下降路径点或末端修正的静止边界估计会话内承重残差；运动中的反馈不学习。
3. 接受窗口必须包含至少 6 帧、持续至少 0.25 秒，逐轴包新鲜度不超过 0.1 秒，并满足固定参考、固定增益、低速度、低漂移及稳定力矩条件。
4. 对绝对残差作有界低通更新，保留最初进入轨迹时的承重锚点；不反复累加同一份 PD 力矩，不修改持久自适应学习文件。
5. 下一段从上一条真实 MIT 命令平滑桥接。静态承重基线的 smoothstep ramp 限速为 1 Nm/s；运动适配器另加的重力增量与动态项保留各自原有限速，该数值不是总前馈的统一限速。
6. 估计值受增益相关修正范围、完整预计算包络的硬件余量及 MIT 力矩边界约束；达到限幅后不继续积分。在线范围不收缩到已发送命令以内。
7. 终点报告分别记录已估计、上一完成段已使用、尚待应用的残差，不把最后一次尚未施加的估计写成已收敛。
8. 新模块加入 prepared plan 的源码指纹。旧版预计算文件必须重新生成或重新完整核验，不能直接复用。

目标关节角、几何路径、TCP、棋盘配准和 Kp/Kd 均未因本次修复改变。肩旋 Kp 上限 36、Kd 4.5及下降增益连续策略保持原样。同串口 Model Hold、自适应学习、实体急停、已确认振荡停止、承重故障保持及普通 Clearance 跳过 shoulder_rotate 的逻辑均保留。
